# CyberChef

Herramienta para codificación, cifrado, hashes, compresión y análisis de datos,
disponible en http://localhost:8085.

```bash
docker compose up -d
```

Para usar otro puerto:

```bash
CYBERCHEF_PORT=9005 docker compose up -d
```

CyberChef procesa los datos en el navegador; el texto y los archivos no se
envían al servidor.
